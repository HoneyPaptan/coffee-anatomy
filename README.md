# Espresso machine

An interactive isometric figure of a compact espresso machine. Press espresso or americano (or keys 1 and 2) to watch the display glow and the coffee pour.

- [Dark](coffee-machine.html)
- [Light](coffee-machine-light.html)

Build with `node build.mjs` (add `--light` for the light theme). Needs the anatomy kit at `~/.claude/skills/anatomy` or `ANATOMY=<path>`.
